# Verification scope

Use the locked dependency installation, Astro check/build, static output inspection, consent and Worker runtime tests, and deployment dry run. All four Indonesian page families must expose unique plain-text metadata, a canonical URL and visible navigation; FAQ schema must equal the visible homepage questions and answers. Unknown URLs must return404/noindex. HTTP and www redirects must retain path and query. Check every local output reference and every generated file included in the commit.

Source code checks do not constitute browser layout or production acceptance. Formal mobile/visual checks and production deployment are separate coordinator gates. Do not describe an attempted check as passed or derive current opening, fees, route availability or water safety from historical photographs and promotional material.
